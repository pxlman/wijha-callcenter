# Fix E2E Tests — Plan

## Root Cause Analysis

### Confirmed Exception Sources

| # | Source | Symptom | Severity |
|---|--------|---------|----------|
| 1 | **PostgreSQL not running** | `P1001: Can't reach database server` on `prisma.$connect()` in `setupE2E()` | Critical |
| 2 | **Database name mismatch** | `setup-e2e.ts` falls back to database `e2e` (`postgresql://myuser:mypassword@localhost:5432/e2e`) while project docs, docker-compose, and seed comments reference `mydb` | Critical |
| 3 | **Schema not deployed** | `P2021: The table "client" does not exist` if `prisma db push` was never run | Critical |
| 4 | **`security.e2e-spec.ts` missing cleanup** | `afterAll` calls `teardownE2E()` but NOT `cleanupTestData()`, leaving dirty state for subsequent suites | High |
| 5 | **Non-null assertions in tests** | `(await prisma.project.findFirst(...))!.id` throws `TypeError` if seed fails or DB is down | High |
| 6 | **`owners.service.ts:329` non-null assertion** | `return toOwnerResponse(updated!)` throws `TypeError` if `findUnique` returns null after `upsert` | Medium |
| 7 | **`app.controller.ts:16` unsafe split** | `dbConnectionStatus[0].version.split(' ')[0]` throws if `VERSION()` returns empty result | Low |

### Most Likely teammate scenario
Teammate ran `npm run test:e2e` without:
- Starting PostgreSQL (`docker compose up -d db` or local postgres)
- Ensuring database `mydb` exists
- Running `npx prisma db push`

This causes immediate connection/table-not-found exceptions across all 9 test suites.

## Task 3: Improve Test Robustness

### 3.1 Add `beforeEach` / `afterEach` cleanup for test isolation
**Files:** All `src/e2e/*.e2e-spec.ts`
- Move `cleanupTestData()` from `afterAll` only to also run in `beforeEach` (or at minimum, ensure every suite cleans up after itself).
- Actually, since `seedTestData` is idempotent, the simplest fix is to ensure every suite's `afterAll` calls `cleanupTestData`. Currently `security.e2e-spec.ts` is the only one missing it.

### 3.2 Fix `calls.e2e-spec.ts` empty-body expectation
**File:** `src/e2e/calls.e2e-spec.ts:155-161`
